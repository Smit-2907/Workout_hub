# Workout Hub 2.0 - Project Plan

## 1. Goal
Workout Hub 2.0 is a comprehensive web platform designed to provide structured home workout routines. It simplifies fitness by categorizing exercises by muscle groups, difficulty levels, and workout types, making it accessible for everyone from beginners to advanced athletes.

## 2. Core Features (MVP)
### User Features
- **Registration & Login**: Secure user accounts.
- **Exercise Library**: Browse a wide range of exercises.
- **Filtering**: Search workouts by muscle group or difficulty.
- **Visual Guides**: Watch workout videos and read step-by-step instructions.

### Admin Features
- **Exercise Management**: Create, Update, and Delete exercise entries.
- **Category Management**: Organize workouts into logical groups.
- **User Management**: Overview of registered users.

## 3. System Roles
| Role | Permissions |
|--- |--- |
| **User** | Browse workouts, filter, view details, manage profile. |
| **Admin** | Full CRUD on exercises/categories, user oversight, admin dashboard access. |

## 4. Feature List
### Public / User Side
- **Landing Page**: Overview of the platform with featured workouts.
- **Exercise Directory**: Searchable list of all exercises.
- **Detail View**: Dedicated page for each exercise with video embed.
- **Profile Dashboard**: User's personal space (future tracking).

### Management / Admin Side
- **Admin Login**: Separate secure entry for admins.
- **Dashboard**: Quick stats on exercises and users.
- **Category Tool**: Add/Remove muscle groups and types.
- **Exercise Editor**: Form-based interface to add new exercises with media links.
